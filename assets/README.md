# Assets Directory

This directory contains static assets for the Schnitzeljagd app.

## Structure

- `icons/` - Application icons
- `images/` - Images and graphics
- `maps/` - Map-related assets
- `sounds/` - Audio files (optional)

## Adding Assets

When adding assets:
1. Optimize images for mobile (compress and resize)
2. Use appropriate formats (PNG for transparency, JPEG for photos)
3. Follow naming conventions: `lowercase_with_underscores.ext`
4. Document usage in this README
